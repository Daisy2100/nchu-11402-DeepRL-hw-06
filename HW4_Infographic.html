Tool Design — Function Calling
TOOL 01
search_papers()
跨學術資料庫搜尋相關論文，支援關鍵字、年份範圍篩選
IN: query, year_range, source, max_results
OUT: 論文列表 (title, DOI, snippet)
TOOL 02
summarize_paper()
深度摘要單篇論文，結構化呈現方法、結果與研究限制
IN: doi_or_url, focus_aspect
OUT: 結構化摘要 (方法/結果/限制)
TOOL 03
compare_literature()
比較多篇論文，找出共識、分歧與研究缺口
IN: paper_ids[], comparison_axes[]
OUT: 比較矩陣 + 綜合分析段落
TOOL 04
cite_formatter()
將論文 ID 轉換為指定格式引用清單（APA/IEEE/MLA）
IN: paper_ids[], citation_style
OUT: 格式化引用字串列表
TOOL 05
generate_report()
整合所有摘要與比較，產出完整結構化文獻綜述報告
IN: topic, summaries[], format
OUT: Markdown 研究報告
